# Dashboard — Document d'explication

## C'est quoi ?

Le **Dashboard** est l'accueil après connexion. L'utilisateur y voit ses 
statistiques, la prochaine collecte, et peut accéder aux fonctionnalités.

| Tab | Icône | Écran |
|---|---|---|
| **Home** | 🏠 | Dashboard (stats, collecte, activité) |
| **Report** | 📸 | Formulaire de signalement |
| **Rewards** | 🎁 | Récompenses (à venir) |
